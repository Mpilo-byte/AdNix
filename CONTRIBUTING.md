# Contributing to AdNix
Thank you for your interest in contributing to AdNix.

AdNix is a community-driven, open-source project built around privacy, user freedom and intelligent web filtering.

I welcome bug reports, feature suggestions, documentation improvements and code contributions.

## Contribution process
All contributions to the official repo must be submitted through GitHub Issues or Pull Requests.

### Project governance
- The project is maintained under a single-owner governance model.
- The project owner retains administrative control and final decision-making authority.
- Community members do not receive direct write access to the official repo.
- All proposed code changes are subject to review.
- Pull requests may be approved, modified, deferred or rejected at the project owner's discretion. 

### How to contribute?
1. Open an issue describing your proposed improvement or bug.
2. Fork the official AdNix repo.
3. Make your changes in your fork.
4. Submit a pull request.
5. Wait for project-owner review.

**Submitting a contribution does not guarantee acceptance.**

## Our philosophy
AdNix is community-driven, but its official codebase is maintained through a controlled review and approval process.
